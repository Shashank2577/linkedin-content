## Post body (copy from here)

Four companies put four layers of the agent stack under one foundation this week. That's the boring news that matters.

On Oct 22, the Agentic AI Foundation added Agent Skills from Anthropic, Open Responses from OpenAI, OpenEnv from Hugging Face, and OpenSandbox from Alibaba. It now hosts 10 projects. MCP, A2A, AGENTS.md and goose were already there.

Look at what the four cover: how agents gain skills, how apps talk to models across providers, where agents are trained and evaluated, and where they run. That's not a random pile. That's a stack.

The practical question is portability. Open Responses defines one request schema and one set of streaming events across providers. Agent Skills packages instructions, scripts and resources so they load on demand across products. If both hold, switching model vendors gets cheaper. If they don't, it's another spec with a logo.

I've watched enough "open standard" launches to wait for the second implementer. The repos are public. Read what each provider actually supports before you promise your team portability.

But the direction is right. The agent stack is consolidating faster than the web stack did.
