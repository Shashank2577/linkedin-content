## Post body (copy from here)

98% of GPT-6.1 Sol's coding quality at 40% of the price.

That's Microsoft's claim for MAI Code 2, announced at Ignite this week.

The same post puts it at 96% of Claude Opus 5.5 at 5% of the price. In Microsoft's own developer preference test, coders picked MAI Code 2 over GPT-6 Sol 64% of the time. The Flash variant is positioned against GPT-6 Luna at 65% of the cost and Claude Haiku 5.5 at 20%.

Those are vendor numbers from a vendor test setup. I haven't run them, and "preferred 64% of the time" depends entirely on which tasks were in the sample.

What I'd actually test is the boring middle of the work: review comments on a 400-line diff, test generation for a legacy Java service, and a migration where the model has to follow a house pattern rather than invent one.

At 40% of Sol pricing, Code 2 doesn't need to win. It needs to be good enough that you stop routing every request to the expensive model. That's a procurement question before it's a benchmark question.
