## Post body (copy from here)

338,115 stars. That's REA, a tool that lets your coding agent take software apart, six months after the repo was created.

REA stands for Reverse Engineer Anything. It's MIT licensed and runs as one local MCP server. Point Claude Code, Codex, Cursor or Gemini CLI at a binary, an Android APK, an Electron app or a website, and it returns findings with the evidence behind them. Deep native analysis uses a Hopper, Ghidra or IDA install you already have.

My favorite example on its site is small. In Windows Calculator, 200 + 10% gives 220, because the percent key takes 10% of the first number after a plus sign. The agent found the logic, and the page checks it against Microsoft's published Calculator source.

The README also lists bigger claims, like a DX-Ball sound calculation rebuilt to pass 3,205 original test cases. Those are the project's own results and I haven't reproduced them.

One thing I'd read before using it: the README says analysis runs locally, but your agent's model provider still has its own data policy. Check both before you point it at anything that isn't yours.
