## Post body (copy from here)

The most important OpenAI announcement this week wasn't a model.

It was a Git storage company.

On Wednesday, OpenAI agreed to acquire Pierre Computer, the team behind Code Storage and the Trees and Diffs libraries. If you've browsed files or reviewed a change in the Codex app, you've already used its work. Terms weren't disclosed and the deal hasn't closed.

Two days earlier, OpenAI published how it scales Git internally with Pando, its own source control backend for engineers and agents.

Two days apart, both point the same way. OpenAI isn't just selling code generation. It wants the storage, history, review and deploy path around the code its agents write.

The model is becoming the commodity. The workflow is the product.

For teams, the question isn't which agent writes the best diff this month. It's which parts of the agent loop you own and which parts you rent. Source control, review state, audit trail, permissions. Those get expensive to move later.

Pierre's open-source libraries stay open source, and existing Code Storage customers keep working. That's the stated plan. It's also true that the same company would own where agent-written code lands and the tool that reviews it.

The deal still needs regulatory approval. The direction doesn't.
