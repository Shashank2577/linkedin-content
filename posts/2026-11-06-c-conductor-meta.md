## Post body (copy from here)

Meta just bought the layer that runs your coding agents in parallel.

On Wednesday, Meta acquired Conductor, the startup behind a macOS app for running multiple coding agents at once in isolated Git worktrees. Conductor was founded in 2024. Terms weren't disclosed.

The timing is the story. OpenAI announced its Pierre acquisition the same day. Both deals are about the same thing: the labs want to own the workflow around the model, not just the model.

Conductor's product is a control plane for parallel work. You split a project into separate worktrees, point agents from Anthropic or OpenAI at each one, and review the results. That's a different problem from code generation. It's coordination, conflict resolution and review.

If you were using Conductor, read the timeline. Conductor Cloud goes read-only Nov 13 and shuts down Nov 20. The local app keeps getting models and fixes until early 2027. New sign-ups stopped Wednesday.

The lesson for teams isn't to buy the next orchestration startup. It's to keep your worktrees, transcripts and review state portable. The layer above the model is where the lock-in is forming.
